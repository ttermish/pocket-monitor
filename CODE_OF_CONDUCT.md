# Community conduct / 社区行为准则

## English

Treat participants with respect regardless of background or experience. Ask questions freely, critique ideas and code rather than people, and provide useful context when giving feedback. Harassment, threats, discriminatory abuse and publication of private information are not acceptable.

Maintainers may ask participants to revise content, remove harmful contributions, or restrict participation when necessary to protect the community. Apply these expectations to project issues, pull requests and other project-managed spaces.

To report a conduct concern, use an existing private maintainer channel. If none is available, ask for one without posting personal details publicly. Reports should describe the behavior and relevant context; maintainers should handle them with care for the privacy of those involved.

## 简体中文

尊重不同背景和经验的参与者。欢迎提问，讨论针对观点和代码，反馈应提供有用的上下文。社区不接受骚扰、威胁、歧视性攻击或泄露他人隐私。

维护者可要求修改内容、移除有害贡献，或在必要时限制参与，以保护社区。以上约定适用于本项目的 Issue、Pull Request 及其他由项目管理的交流空间。

遇到行为问题，请通过已有的维护者私密渠道反馈；若没有渠道，先请求私密联系方式，不公开当事人信息。报告应说明具体行为及上下文，维护者处理时应尊重相关人员隐私。
