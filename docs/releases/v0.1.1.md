随身屏 0.1.1，Android 8.0+ 开发测试版。

将 Mac / NAS 的 HDMI 输出经 UVC 采集卡接入 Android 手机，即可预览画面。

本次更新：

- 记住每种采集卡持续出帧至少 3 秒的格式，下次连接优先恢复。
- 启动 8 秒无帧或视频启动异常时，尝试设备支持的较低规格，最多降级重连两次。
- 第一帧到达后立即切换为实时画面状态，不再等待每秒统计刷新。
- 隔离旧连接的视频帧统计，避免拔插或切换格式时旧回调影响新连接。

自动化构建运行共享测试、Android 单元测试和 Release Lint，并检查 APK 签名、证书指纹、AAB 签名和 APK 的 16 KB ZIP 对齐。具体结果以对应工作流记录为准。

签名工作流生成 `pocket-monitor-0.1.1-release.apk` 和 AAB。Release APK 使用专用签名，无法直接覆盖此前的 Debug 安装；卸载会清除已保存的格式。AAB 不能直接安装。`SHA256SUMS` 提供附件校验值，`BUILD_INFO.json` 记录对应提交，项目源码、UVCAndroid AAR、对应源码和第三方许可随附件提供。

本地早期 `v0.1.1` 标签仍对应 Debug 阶段提交，不代表已发布以上签名产物；手动工作流仅上传 Actions artifact，GitHub Release 由后续匹配版本的新标签触发。

当前开发环境没有手机和采集卡，尚未完成 Mac HDMI → 采集卡 → 手机的真实视频验证。仅支持视频预览；不包含音频、键鼠回传或 iPhone 版本。
